# 카드뉴스 6장 — 나노바나나 이미지 프롬프트

각 프롬프트는 따로 복사해서 쓸 수 있도록 공통 스타일을 매번 포함했어요.
비율은 인스타그램 카드뉴스용 4:5 (1080×1350) 기준이에요.

## 1장 · 표지
```
인스타그램 카드뉴스 표지, 세로 4:5 비율.
화면 중앙에 두 손이 결혼 답례품 상자를 들고 있는 사진 같은 장면. 상자 안에는 꽃차 병과 개별 포장된 약과가 담겨 있고, 은은한 분홍빛 꽃다발 일러스트 스티커가 붙어 있다.
배경은 따뜻한 크림색, 부드러운 자연광, 위쪽에 글자를 넣을 여백.
상단 작은 글씨: "따로 요청드릴 디자인이 없는데, 가능할까요?"
중앙 큰 제목(굵은 한글 고딕): "디자인 몰라도 괜찮아요"
제목 아래 부제: "결혼 답례품 스티커, 문구만 있으면 돼요"
전체 톤: 크림색, 연분홍, 세이지 그린. 단정하고 따뜻한 감성, 과하지 않게.
한글 글자는 정확한 맞춤법으로 또렷하게, 위 문구 외 다른 글자는 넣지 말 것.
```

## 2장 · 알려주실 건 세 가지뿐
```
인스타그램 카드뉴스 본문 페이지, 세로 4:5 비율.
크림색 배경에 연분홍 꽃잎 일러스트가 모서리에 살짝 장식된 깔끔한 레이아웃.
상단 제목(굵은 한글 고딕): "알려주실 건 세 가지뿐"
그 아래 세로로 둥근 카드 3개, 각각 작은 아이콘과 함께:
1. 달력 아이콘 + "어떤 행사인지"
2. 사람 아이콘 + "누구에게 드리는지"
3. 말풍선 아이콘 + "전하고 싶은 문구"
하단 작은 글씨: "문구가 막막하면 행사와 받는 분만 알려주세요"
색감: 크림색, 연분홍, 세이지 그린. 미니멀하고 단정한 플랫 일러스트 스타일.
한글 글자는 정확한 맞춤법으로 또렷하게, 위 문구 외 다른 글자는 넣지 말 것.
```

## 3장 · 시안은 이렇게 진행돼요
```
인스타그램 카드뉴스 본문 페이지, 세로 4:5 비율.
크림색 배경, 위에서 아래로 이어지는 4단계 타임라인 인포그래픽. 단계마다 동그란 번호 배지와 작은 플랫 아이콘.
상단 제목(굵은 한글 고딕): "시안은 이렇게 진행돼요"
① 장바구니 아이콘 + "주문"
② 종이 시안 아이콘 + "시안 전달"
③ 연필 아이콘 + "확인과 수정"
④ 스티커 붙은 선물상자 아이콘 + "제작"
하단 작은 글씨: "수정은 언제든 편하게 말씀해주세요"
색감: 크림색, 연분홍, 세이지 그린. 단정하고 부드러운 플랫 디자인.
한글 글자는 정확한 맞춤법으로 또렷하게, 위 문구 외 다른 글자는 넣지 말 것.
```

## 4장 · 스티커 스타일 4가지
```
인스타그램 카드뉴스 본문 페이지, 세로 4:5 비율.
크림색 배경에 동그란 원형 스티커 4개를 2×2 격자로 배치한 장면. 각 스티커 아래에 짧은 이름표.
1. 노란 들꽃이 동그랗게 둘러진 리스 안에 귀여운 신랑신부 일러스트 — 이름표 "들꽃 리스"
2. 주황빛 꽃과 연한 잎이 둘러진 수채화 꽃 리스 — 이름표 "수채화 리스"
3. 하얀 꽃, 초록 잎, 작은 새가 어우러진 장식과 영문 필기체 "Happy Wedding" — 이름표 "화이트 플라워"
4. 필기체 "Thank you" 아래 신랑신부 일러스트 — 이름표 "Thank you"
상단 제목(굵은 한글 고딕): "분위기 따라 골라보세요"
스티커 안에는 작은 글씨를 넣지 말고 그림 위주로. 부드러운 그림자로 실제 스티커처럼.
색감: 크림색 배경, 연분홍 포인트. 단정하고 따뜻한 감성.
한글 글자는 정확한 맞춤법으로 또렷하게, 위 문구 외 다른 글자는 넣지 말 것.
```

## 5장 · 문구, 이렇게 써보세요
```
인스타그램 카드뉴스 본문 페이지, 세로 4:5 비율.
크림색 배경에 연분홍 메모지 4장이 세로로 살짝 겹쳐 붙어 있는 레이아웃, 모서리에 작은 꽃잎 장식.
상단 제목(굵은 한글 고딕): "문구, 이렇게 써보세요"
메모지마다 작은 태그와 문구:
- 태그 "담백하게" / "함께해주셔서 감사합니다."
- 태그 "회사·동료에게" / "보내주신 축복 잊지 않고 행복하게 살겠습니다."
- 태그 "어른들께" / "귀한 발걸음 해주신 은혜 잊지 않겠습니다."
- 태그 "친구에게" / "와줘서 고마워, 행복하게 잘 살게!"
하단 작은 글씨: "스티커 문구는 두세 줄 안쪽이 읽기 편해요"
색감: 크림색, 연분홍, 세이지 그린. 손편지 느낌의 따뜻한 디자인.
한글 글자는 정확한 맞춤법으로 또렷하게, 위 문구 외 다른 글자는 넣지 말 것.
```

## 6장 · 마무리
```

나무 테이블 위에 놓인 결혼 답례품 세트 사진 같은 장면: 꽃무늬 리스 라벨이 붙은 꽃차 병, "감사합니다" 꽃무늬 스티커가 붙은 개별 포장 약과. 부드러운 자연광, 크림색 톤, 위쪽에 글자 여백.
상단 큰 글씨(굵은 한글 명조): "문구는 마음, 디자인은 그 마음을 예쁘게 입히는 일"
하단 둥근 박스 안 작은 글씨:
"주문은 네이버 스마트스토어 '다정카페'"
"문구가 고민되면 톡톡으로 상황만 남겨주세요"
색감: 크림색, 연분홍, 세이지 그린. 단정하고 따뜻한 감성.
```
